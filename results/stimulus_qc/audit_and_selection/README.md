# CFD audit and stimulus selection QC

Original manifest: 597 models.

Selected pool: 135 models, before age matching.

Generated by `scripts/stimulus_preparation/02c_plot_stimulus_qc.py`.

Inputs: `data/interim/cfd_audit/cfd_manifest_harmonised.csv` and `data/processed/stimuli.csv`.

Figures are saved as PNG and PDF; aggregate tables as CSV.

The self/perceived heatmap is normalised within each self-reported category. It describes category correspondence, not classification accuracy.

Perceptual proportions are CFD norming response proportions, not classifier confidence scores.

Selection counts compare the full database with the eligible pool; they do not isolate the effect of individual filters.

These results do not describe the final age-matched pool or establish population representativeness.
